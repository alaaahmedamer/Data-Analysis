# 📊 Project Showcase: Interactive Business Intelligence Dashboard

### 🎯 Project Overview
This repository contains my latest Data Analysis project, where I developed a comprehensive, end-to-end interactive dashboard. The goal of this project was to clean raw business data, analyze key performance indicators (KPIs), and present automated visual insights to support strategic decision-making.

### 🛠️ Tech Stack & Tools Used
* **Data Visualization & Analytics:** Power BI 
* **Data Transformation:** Power Query
* **Data Modeling:** DAX Formulas

### 📂 Dataset Details
* **Source:** Business Performance and Sales Dataset.
* **Key Metrics Analyzed:** Revenue trends, profit margins, regional performance, and top-performing categories.

### 💡 Key Insights Delivered
1. Identified the core growth drivers and seasonal sales peaks.
2. Uncovered underperforming segments to optimize operational efficiency.
3. Designed dynamic filters (Slicers) for continuous, real-time data filtering.
